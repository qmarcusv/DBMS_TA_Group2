How we worked

One shared database backup, one shared set of three queries, one branch per role in Git, and an integration branch that merged the chapters into a single LaTeX report. Numbers were re-measured on one machine so the chapters agree with each other.

Tooling note

The integration additions marked above, the measurement scripts behind them and the SSMS screenshots of Chapter 3 were produced during integration by Vũ Minh Quân with an AI coding assistant (Claude Code), which drafted text and automated screenshot capture from SSMS.
