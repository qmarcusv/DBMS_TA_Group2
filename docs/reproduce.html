Reproduction guide

Rebuild every result in SQL Server Management Studio

No programming environment is needed: restore one backup, open the scripts in SSMS, select a block and press F5. The repository README has the same guide with line numbers.

  1. InstallSQL Server 2022/2025 + SSMS
  2. Restoredata/SpineMRI_DBMS.bak
  3. Open a scriptsql/ folder
  4. Select a blockthen press F5
  5. Comparewith the numbers in the report

Numbers will differ slightlyPage counts (logical reads) reproduce exactly. Estimated rows depend on sampled statistics, and times, memory grants and the degree of parallelism depend on your machine; the plan shapes and the ratios between alternatives stay the same.
